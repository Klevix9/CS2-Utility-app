# Privacy policy

_Last updated: 18 November 2026_

CS2 Utility does not collect, store on any server, or share any personal data.

- The app has no accounts, analytics, ads or tracking.
- It doesn't use the internet.
- Lineups you create, screenshots you attach and a radar image you choose are stored only on your device, in the app's private storage. Uninstalling the app deletes them.
- When you export lineups, the app writes a file to the place you pick. When you import, it reads only the file you pick.
- Picking images uses Android's photo picker, so the app only sees the images you choose.

Questions: open an issue on the project's GitHub page.
